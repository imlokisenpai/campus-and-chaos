{%- comment -%} ══ How to contribute ══{% endcomment -%}
This is a group project

Bring your own disasters

Nobody remembers everything, and that's the whole problem. If you've got a photo, a 12-second clip, or a story that only makes sense to you and four other people — it belongs in here.

Adding something takes about two minutes. You don't need to install anything; you just add a file on GitHub and the site updates itself.

How to add yours Meet the batch

Rules:

1. Photos over paragraphs.

2. Blur the faces you don't want immortalised.

3. Write the date, even if it's "sometime in second year".

— Loki
